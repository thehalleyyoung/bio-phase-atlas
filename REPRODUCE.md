# Reproducing the results

All numbers in `README.md` and `docs/paper/tool_paper.tex` are generated by
`scripts/make_summary.py` from the raw files under `results/`.

## Environment

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install numpy==2.5.3 scipy==1.18.1 sympy==1.14.0 mpmath==1.3.0 \
            z3-solver==5.1.0.0 python-libsbml==5.21.2 pyyaml DSGRN==1.10.0 pytest pytest-timeout
```

Basic operations use outward binary64 rounding. Exponential and logarithmic
bounds use 100-bit mpmath interval operations followed by outward conversion.
The cloud runs used Modal (`pip install modal`, account configured in
`~/.modal.toml`); every run is logged with duration and estimated cost in
`results/modal_costs.jsonl`. No paid LLM API was used
(`results/api_costs.jsonl` is empty).

## Data

`data/biomodels/*.xml` were downloaded from
`https://www.ebi.ac.uk/biomodels/model/download/<ID>?filename=<ID>_url.xml`
(BIOMD0000000003, -05, -09, -10, -26). SHA-256 sums: `data/biomodels/SHA256SUMS`.

References in the paper were checked against Crossref with
`python3 docs/paper/verify_refs.py` (output `docs/paper/refs_check.json`).

## Arithmetic and nonlinear controls

```sh
PYTHONPATH=. python3 audit/nonlinear_boundary.py audit/results/nonlinear-after.json
PYTHONPATH=. python3 audit/followup.py
python3 -m pytest tests/test_certified.py tests/test_rounding_boundary_audit.py tests/test_extended_interval_audit.py -q
```

The frozen plans and initial outputs remain in `audit/`. New controls are
synthetic analytical checks; headline atlas totals are archived reanalysis.
The audit used an owned `.venv` with system packages plus the binary
python-libsbml 5.21.2 wheel; install commands and receipts are recorded there.

Extended-bound review controls can be replayed with:

```bash
.venv/bin/python audit/extended_exact_oracle.py "$PWD" > audit/results/extended-exact-oracle-after.json
.venv/bin/python audit/extended_nan_exclusion.py "$PWD" > audit/results/nan-exclusion-after.json
```

The oracle script preserves the reviewer's embedded original revision label;
its output hashes identify the actual arithmetic source executed.

## Fresh post-repair controls

```sh
OPENBLAS_NUM_THREADS=1 python3 audit/wave2/boundary_compare.py > audit/wave2/results/boundary-comparison.json
OPENBLAS_NUM_THREADS=1 python3 audit/wave2/extended_attacks.py > audit/wave2/results/extended-attacks.json
python3 -m pytest -q tests/test_extended_interval_audit.py
sh scripts/build_paper.sh
```

These controls do not rerun the historical atlas or external-checker archives. Root `tool_paper.pdf` is the only publication PDF; `audit/wave2/pdf-archive-manifest.json` records superseded versions.
