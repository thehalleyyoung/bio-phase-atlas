# Review: Certified Phase Atlases for Biological ODE Models

**Reviewer:** Lila Zhang (Symbolic Reasoning and AI Expert)
**Score: 7/10**

---

The SMT certificate generation pipeline is the core symbolic reasoning contribution of this proposal, and it addresses a genuine gap: no existing tool produces machine-checkable certificates for regime classifications of biological ODE models. The tiered approach—from interval arithmetic (Tier 1) through δ-complete SMT (Tier 2, dReal) to exact verification (Tier 3, Z3 on QF_NRA)—correctly maps the decidability landscape of the underlying theories and provides graceful degradation when stronger certificates are infeasible.

**Strengths.** The soundness theorem B1 for δ-complete SMT encoding of regime claims is the central symbolic contribution. The formalization that if dReal returns UNSAT the regime claim holds up to δ-perturbation, with explicit characterization of the gap between δ-soundness and exact soundness, provides a rigorous logical foundation for the certification pipeline. The certificate composition calculus (B2)—composing certificates from subregions into certificates for larger regions with soundness-preserving hierarchical composition—is a practical contribution to proof management that enables scalable certification. The requirement for overlap or explicit boundary certificates between adjacent regions handles the subtle boundary soundness issue that naive composition misses. The Tier 3 exact verification via Z3 on QF_NRA for polynomial-only models (mass-action kinetics without Hill functions) provides the strongest possible certificates for the decidable fragment, and the 59/59 equilibrium verification result across benchmark models demonstrates practical feasibility. The SMT-LIB2 format output enables independent certificate verification by any SMT-LIB-compliant solver, supporting reproducibility.

**Weaknesses.** The δ parameter in dReal's δ-complete decision procedure introduces a fundamental logical gap: a δ-UNSAT result certifies the claim up to perturbation δ, but the mapping from δ to the biological meaning of "close enough" is domain-specific and the proposal does not formalize how δ is chosen for biological applications. Too large a δ provides weak guarantees; too small a δ may cause dReal to timeout. The Tier 2/3 boundary is determined by whether the model contains transcendental functions, but this is a syntactic criterion—some models with transcendental functions can be soundly over-approximated by polynomial models (e.g., Hill functions with integer exponents are polynomial), and the system should exploit this. The formula simplification step ("soundness-preserving formula simplification") is mentioned but not specified—simplification of nonlinear arithmetic formulas can introduce subtle soundness issues if not carefully implemented. The certificate size and verification time metric is included in the evaluation plan but without baseline comparison: what is the expected ratio of certificate size to problem size, and does independent verification scale linearly or super-linearly with certificate complexity? The parameter-dependent Krawczyk theorem (A2) requires uniform contraction over the parameter fiber—this is feasible when the Jacobian is well-conditioned throughout the parameter box but can fail near bifurcation points where eigenvalues cross the imaginary axis. The proposal acknowledges handling "near-singular Jacobians at bifurcation points" but the symbolic encoding of near-singularity conditions for SMT verification is technically challenging and underspecified.

**Verdict.** The SMT certification pipeline is logically sound and the tiered architecture is well-designed. The main concerns are δ-selection for biological relevance, formula simplification soundness, and the handling of near-bifurcation regions where both the Krawczyk operator and SMT verification face difficulties. A focused paper on the B1 soundness theorem with the toggle-switch demonstration would be a strong submission.
